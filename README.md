 📊 Customer Churn Analysis | Power BI

Overview
This project analyzes customer churn in a telecom company using Power BI to identify key factors affecting customer retention.

Key Insights
- Month-to-month contracts have higher churn  
- Electronic check users churn more frequently  
- Low tenure customers are more likely to churn  

 Features
- Interactive Power BI dashboard  
- Slicers for Gender, Contract, and Internet Service  
- Consistent churn color coding (Yes / No)

Tools Used
Power BI | Data Visualization | DAX | Data Analysis
